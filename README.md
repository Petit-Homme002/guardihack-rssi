# GuardiHack — Cellule RSSI

Maquette indépendante et interactive de simulations de crise cyber.

## Démonstration

https://Petit-Homme002.github.io/guardihack-rssi/

Trois scénarios originaux, quatre décisions par scénario :

- Phishing : débutant, 90 secondes par décision.
- Rançongiciel : intermédiaire, 60 secondes par décision.
- Prestataire compromis : expert, 40 secondes par décision.

Impacts fictifs sur la continuité, la confiance, les données et les équipes ; budget simulé, bilan exportable et progression locale. Aucun compte des sites de référence n’est connecté.

## Utilisation locale

Ouvrir index.html dans un navigateur récent ou servir ce dossier avec un serveur HTTP statique. Les fichiers index.html, style.css et app.js suffisent. Les polices Google Fonts nécessitent Internet ; des polices de repli sont prévues.

## Hébergement

GitHub Pages : branche main, dossier racine. Aucun outil de compilation nécessaire. Modifier les fichiers sur main met à jour la démo.

## Limites

Prototype côté navigateur : pas de serveur de jeu, de comptes, de classement partagé ni de protection anti-triche. Les étapes sont fixes ; les choix modifient les indicateurs, le score et les explications. Montants et scores pédagogiques fictifs. Les résultats restent dans le navigateur et peuvent être modifiés localement.

L’intégration à GuardiHack nécessitera une authentification et une validation des décisions, des chronos et des scores côté serveur. Les scénarios doivent être relus avant un usage en compétition.
